Petite Mort · Direction A — Warm Editorial

The post-purchase email set

Seven transactional emails covering the whole journey from checkout to refund, all in the approved Direction A language. Each one has a browser preview with sample data and a production Shopify Liquid template beside it.

Nothing here is live. No Shopify notification template has been changed. These are staged for review — Shopify has no draft state for transactional notifications, so the repo is the draft. See INSTALL-RUNBOOK.md before pasting anything.

Order

Order confirmation

Fires on order paid · highest volume

Delivery window, four-step progress rail, itemised totals, the gift-card promise, and the four FAQs that remove the most support tickets.

Approved

Order cancelled

Fires when an order is cancelled

Leads with where the money goes and when. Adapts when there is no payment to return. Muted panel rather than the warm blush — bad news in a celebratory tint reads as tone-deaf.

Preview Liquid

Refund notification

Fires on every refund, full or partial

Exact amount, which account it returns to, the date it should land, and a three-step bank-processing rail. Detects partial refunds and states what is still paid, so a partial never reads as a full reversal.

Preview Liquid

Shipping

Shipping confirmation

Fires on fulfilment · second highest volume

Arrival window recalculated from despatch, carrier and tracking number, and the contents of this specific parcel. Detects a partial shipment and says the rest is coming separately.

Preview Liquid

Shipping update

Fires when tracking changes

Gives a revised window and a hard commitment: if it hasn't arrived by a stated date we open the claim ourselves. Says plainly that cancelling for a full refund is still available mid-transit.
